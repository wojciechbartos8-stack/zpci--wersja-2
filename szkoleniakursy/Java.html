Programowanie Java

Kogo zapraszamy?

Szkolenie przeznaczone jest dla wszystkich osób chcących rozpocząć naukę programowania w języku Java.

Uczestnik zdobywa praktyczne umiejętności tworzenia aplikacji oraz pracy z obiektowym podejściem do programowania.

Termin, organizacja i metodyka szkolenia

Zajęcia organizowane są indywidualnie lub dla grup zorganizowanych. Terminy ustalane są elastycznie i dopasowywane do uczestnika.

Szkolenie prowadzone jest w formie praktycznych ćwiczeń komputerowych, nastawionych na zdobycie praktycznych umiejętności programistycznych.

Zakres szkolenia

  • Podstawy języka Java
  • Zmienne i typy danych
  • Operatory
  • Instrukcje warunkowe
  • Pętle
  • Tablice
  • Metody
  • Programowanie obiektowe
  • Klasy i obiekty
  • Dziedziczenie
  • Interfejsy
  • Obsługa wyjątków
  • Tworzenie aplikacji konsolowych
  • Praca w środowisku IntelliJ IDEA lub Eclipse

Efekty szkolenia

Po ukończeniu szkolenia uczestnik potrafi samodzielnie tworzyć aplikacje w języku Java, zna zasady programowania obiektowego oraz jest przygotowany do dalszej nauki technologii Java wykorzystywanych przy tworzeniu aplikacji desktopowych i internetowych.
